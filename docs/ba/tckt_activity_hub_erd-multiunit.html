TCKT Activity Hub — Multi-unit ERD proposal

Proposed target model based on the current TCKT schema and the agreed plan: users can belong to multiple units; BTV assigns work to TCKT; TCKT manages its internal activities/tasks and submits reports back. Existing operational entities are retained. Multi-unit and directive/report entities are additions, not claims about the current live schema. Confirm exact columns and constraints against Core migrations before implementation.
